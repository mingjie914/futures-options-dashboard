# 指标与信号合同

## 版本

- 指标版本：`metrics-v2-reference`
- 信号与验证版本：`signals-v2-reference`
- 跨期最小单腿：`300` 手
- 席位异动倍数：`2.0 ×` 当日品种平均单腿绝对变化
- 当前分位窗口：`504` 个交易日
- 规律库隔离：`25` 个交易日
- 规律库窗口：`1260` 个交易日
- 验证周期：`5`、`10` 个交易日

公式、阈值或样本边界变化时必须增加版本，不在已发布批次上静默改写。

## 基础指标

```text
净持仓 = 多头持仓 - 空头持仓
净变化 = 多头变化 - 空头变化
上一日净持仓变化 = 当前净持仓 - 同品种同席位上一可用交易日净持仓
多空比 = 总多头 / 总空头
多头 CR5 = 多头持仓前 5 名之和 / 品种总多头
空头 CR5 = 空头持仓前 5 名之和 / 品种总空头
净 CR5 = 绝对净持仓前 5 名之和 / 全部席位绝对净持仓之和
F2 = 品种净持仓 / (品种总多头 + 品种总空头)
```

分母为零时返回空值。页面百分比将比例乘以 100；例如 RB 在 `2026-07-28` 的 F2 为 `-3.534642%`，净 CR5 为 `43.935091%`。

“净持仓变化 Top10”使用相邻可用交易日净持仓之差，不等同于源表的日内 `净变化`。新出现席位以上一日 0 处理，退出席位以当日 0 处理。

## 组合一致性

系统组合成员来自 `config/combinations.json`。同一交易日、品种、组合满足以下条件才发布：

1. 配置中的全部成员均有该品种数据。
2. 全部成员净持仓符号一致且不为零。
3. `direction` 由净持仓共同方向决定。
4. `net_position`、`net_change` 为成员求和。
5. 仅当全部成员净变化符号也一致且不为零时发布动作：`add_long`、`reduce_long`、`add_short` 或 `reduce_short`。

四类背离卡固定比较：

```text
主力代理 = 资金突击队
散户代理 = 卧龙凤雏
```

发布“主力加空/散户加多、主力加多/散户加空、主力减多/散户减空、主力减空/散户减多”四类组合动作。它是参考图组合规则，不是对全部席位官方身份的推断。

## 席位异动

### 单腿异动

对每个品种分别计算当日基线：

```text
平均单腿绝对变化 = avg((abs(多头变化) + abs(空头变化)) / 2)
```

每个席位的多头腿和空头腿独立比较；绝对变化达到基线 `2.0 ×` 时发布 `long_surge`、`long_drop`、`short_surge` 或 `short_drop`，证据记录腿别、变化、基线、倍数和净持仓。

### 多空反转

同品种同席位相邻可用交易日净持仓符号相反，且当前绝对净持仓不低于 `300` 手。证据保存前值、当前值和实际净持仓变化。

## 跨期反向

由非汇总 `raw_seat_position` 先聚合为交易日 × 品种 × 合约 × 席位。合约按数字后缀和代码排序；同席位存在一对方向相反且绝对净持仓均不低于 `300` 手的合约时发布信号。

页面展示排序最靠前的反向合约对，同时返回该席位当日全部非零合约腿，便于与参考图一样核查完整期限链。“近远月反向”只表示结构，不确认套利或锁仓动机。

## 当前分位与历史验证

F2 与净 CR5 的当前分位在截至评估日最近 `504` 个交易日内计算：

```text
当前分位 = 窗口内因子值 <= 当前值的样本数 / 窗口样本数 × 100
```

分位 `>= 70` 为高档，`<= 30` 为低档，其余为中档。规律库先从评估日向前隔离 `25` 个交易日，再最多取 `1260` 个交易日，杜绝近期样本及其远期收益越过截点。

规律库按自身 30%/70% 分位选取与当前高低档相同的历史样本，分别计算主力合约收盘价后第 5、10 个交易日价格涨跌幅。结果包括均值、中位数、上涨比例、Wilson 95% 区间和样本量。API 保留字段名 `win_rate` 以兼容现有合同，含义是价格收益大于零的样本比例，不是按多空方向执行后的策略胜率；结果未计手续费、滑点与换月影响。

- 净 CR5：根据历史该档均值正负发布“偏多/偏空”；样本不少于 60 且上涨比例偏离 50% 至少 3 个百分点时为可用，30–59 为样本偏少，其余不可用。这是现有研究规则的状态判定，不等同于已证明可交易性。
- F2：提供当前分位和两期历史样本结果，但不据此发布方向规律，状态保持不可用，防止把参考图未定义的因子含义扩展为交易信号。
- 中档没有高/低极值可比集合时保留分位和后续窗口，收益统计留空。

所有历史结果用于研究比较，不构成交易建议、可交易收益或收益承诺。

## 标签治理

人工标签必须保存 `source`、`valid_from`、`valid_to`、`confidence`、`evidence_json` 和 `note`。动态信号必须携带 `rule_version`、阈值和可复核证据。参考图中“疑似套利”始终保留“疑似”措辞并限制品种与有效期。
