## 已修正的重复和误读

- 删除重复英文装饰标题、组合页重复验证表、跨期页重复异动表、重复品种跳转和无功能占位按钮。
- 全市场矩阵与当前品种详情分区；全部品种时不再取第一品种的 F2、分位或研判冒充市场结论，不混画不同品种的合约链。
- “今日”改为所选交易日语境；区分交易日期、快照发布时间和批次。超过 48 小时仅提示快照较旧，尚未宣称基于交易日历识别缺报。
- 按需读取的同屏响应必须来自同一数据版本；切换期间自动重试，失败保留同页上一成功视图并明确报错，不切换演示数据。历史详情遵守当前日期筛选，避免查看历史时混入后续数据。
- 历史抽屉限制表格滚动区域、近期曲线和明细倒序；横向顶部导航、下拉与键盘焦点可操作，320/390/768 px 无整页横向溢出。

## 仍应优先完善的研究与数据问题

| 优先级 | 问题与影响 | 建议及前置条件 |
|---|---|---|
| 高 | 未上榜、源缺失与真实零持仓仍可能混淆，影响新出现/退出和异动幅度 | 上游发布覆盖率、缺失原因、是否完整等字段；再区分不可比变化与真实变化，变更公式须升级版本 |
| 高 | 价格收益未经可交易主力换月、手续费和滑点处理；重叠样本也可能影响区间解释 | 独立研究验证可交易价格链、样本依赖和样本外效果；当前保持“研究统计”用途 |
| 高 | 全市场异动与验证接口有分页上限，浏览器滚动只覆盖当前加载段 | 接通服务器分页或按需加载；不一次下载全部历史。当前 UI 已明确已加载范围 |
| 中 | 绝对手数容易突出大品种；多个组合共享席位，数量不代表多份独立证据 | 未来并列同品种历史分位或相对持仓变化；提供独立成员覆盖数。需要冻结分母、历史窗口和去重口径 |
| 中 | 缺少真实最后交易日、交割期和交易日历，无法可靠判断临近到期或数据应到未到 | 接入可靠合约元数据和日历，再恢复倒计时/陈旧判定；不按统一每月某日估算 |
| 低 | 重复选择关注品种与日期增加研究操作成本 | URL 已保留页签与品种；如需进一步减少重复操作，可考虑本地自选列表，无需新增账号系统 |

公开上线前仍需确定数据再分发许可、公开字段范围、生产更新责任与失败回退，以及主站路径/同源 API 合同。这些不等于新增登录门槛。当前测试运行副本可脱离原始数据目录，但生产云端取数和发布链尚未完成。
