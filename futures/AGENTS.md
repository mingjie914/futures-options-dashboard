# 期货模块维护约定

- 遵守仓库根目录 AGENTS.md 和 docs/部署与统一维护入口.md；本目录是唯一期货源码，不维护旧机器副本。
- 日常预览使用 http://127.0.0.1:8790/futures/；本目录 start.py 委托根启动器，--standalone 仅供独立调试。
- 在本目录运行 pytest，避免与期权 backend 包名冲突。改前端后从仓库根构建；本地发布使用 tools/publish_futures.ps1，先正常停止本次启动器。
- 保留审阅、候选与生产数据用途边界；构建不采集、不调用 Wind/RQ，不覆盖历史研究记录。生产部署由云服务器会话按已确认方案执行。
