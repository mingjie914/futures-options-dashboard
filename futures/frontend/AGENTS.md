# 期货前端约定

遵循仓库根 `AGENTS.md`、`README.md` 及统一部署文档；本文件仅补充当前期货业务约定，历史迭代以 Git 记录为准。

## 维护与验证
- 权威源码为本目录 `src/`，统一前端的 `frontend/src/futures` 为生成副本，不双份修改。复用共享导航、Metric、请求和图表引擎；保持按需加载和样式隔离。
- 正常验收使用统一前端 build、typecheck、test，并在统一入口检查交互与窄屏。只维护统一构建与发布入口，不安装第二套依赖。
- 不恢复已移除的基本面、数据状态、模拟交易、成本记录、自选、导出或打印界面。相关历史资料、数据校验及离线研究接口不随界面清理删除。

## 页面与交互
- 导航前两项为“季节持仓”“跨期价差”。季节持仓同页上下展示同月持仓和总持仓；历史合约只保留全合约真实日期总览。保留旧 URL 的必要映射，不恢复旧栏目。
- 跨期价差共用“价差季节性 / 价差走势 / 期限曲线”选择（annual/current/curve），筛选顺序为品种、视图、近月、远月、观察日及当前视图参数。期限曲线可下钻选定合约对；价差统计仅随价差图展示，不独立设风险页。
- 价格统一收盘价，品种显示“代码/名称”，选择值保持代码。品种与指标不加重复外部标签，选择框等宽、当前值加粗，窄屏自然换行。筛选刷新保留、全站品种共用遵循根约定。
- 雷达按具体合约对、单合约、品种合计区分对象，同对象异常合并；方向用“多近空远 / 空近多远”。分组、筛选阈值、方向在后端计算，不因精简前端改变。量仓异常、短样本或质量不足不给方向，量价分位不套用席位阈值。
- 指标名与值同行，解释复用 Metric 悬停提示并兼容键盘/触屏；删除直白导读、重复标题、说明折叠与调试信息。保留必要的单位、样本、实际日期差异、缺失/降级及测试标记，不额外堆叠说明。
- 同日期轴的多图联动节选；持仓换月两腿图例同步、远月占比图例独立。不同日期语义、执行价和到期月份不强制联动；拖动不重新请求、不改变统计窗口，卸载解绑。
- 观察日沿用 ObservationDate，清空回到最新；不恢复开始日期控件。历史跨度、价差快捷范围和图内日期节选各司其职，不能把视觉范围当作统计样本范围。

## 数据口径
- 使用真实合约，不以连续主力拼接延长合约对历史；按真实观测对齐，空值不补零、不前填、不混频。持仓/成交以整数手展示，其他图表数值最多两位小数，数值列及表头右对齐。
- 同月跨年对比保持交割年与实际观测日期对应；价差按同月份组合及交割年相对月日对齐，当前年缺失时不把最后历史年冒充当前。持仓手数与品种占比分开，不以未来峰值归一化，不伪造到期日或未核验年化。
- 总持仓读取全部已有历史，默认最近五个有效年份，支持全部年份；图例、颜色、实际日期和数值准确对应。持仓换月分别读取两腿完整历史，以日期并集对齐，不由另一腿上市或缺价截断；选定两腿不同且按月份排序。
- 持仓异常 TOP10：先取当日最大持仓真实合约，再应用量仓门槛；偏离为当前持仓除以前五个交割年份同月合约已观测最高持仓减一。不含当前合约，不用同期值或峰值均值；不足五年显示实际年数，无正历史峰值不排名。
- 历年同期统计与当前合约历史波动保持各自样本范围；风险窗口不把共同历史开始前计为缺口，生命周期内缺口仍剔除。标准差与最大上涨/下跌沿用后端口径，零与缺失区分，不解释为情景盈亏或独立交易胜率。
- 股指基差为现货收盘减期货收盘，正值表示期货贴水；基差率以现货为分母、非年化。CU 为周频参考价差，按分支保留单位与频率，指数点不得写成元/吨。成本、分红、准确到期未核验前不加入交易方向或雷达排名。
- 未审阅来源和连续期货候选不得自动变成现货、已接受基本面或交易准入；观测期截止不代表历史当时可得。来源身份、截图日期与本地数据水位区分，接口和构建不自动取数或消耗供应商额度。
