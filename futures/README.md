## 历史合约功能更新（2026-09-07）

进入左侧“历史合约”：

- **同交割月对比**：选择1—12月，按交割年份叠加历年实际合约；可切换持仓手数、占当日品种总持仓比例、收盘/结算价格、成交量。末个交割年份跟随顶部近月合约，月份由页内控制。
- **固定月份价差**：指定近/远月份及远月同年/次年。近价−远价，仅同日有效双腿；悬停附真实日期和两腿价格。
- **全合约总览**：真实日期上的全部价格曲线、持仓手数热力图、持仓占比热力图。每条序列/每行均为实际月合约，不拼接主力。
- 默认5年，可切3/10年，按视图懒加载。Y-1为近月交割前一年，Y+0为交割当年；保留闰日和空值，不是剩余到期日。权威最后交易日和交易日历未接入前，不启用剩余交易日对齐。
- 比较窗口独立于顶部开始日期，以顶部数据截止日为上界。为覆盖早期生命周期，读取额外最多两年历史；源数据缺失和更早挂牌可能导致截断，展开“口径与数据覆盖”可查看各序列有效首末日期与观测数。10年仅表示请求范围，不保证数据源有完整10年。
- 图表持仓/成交数显示整数，价格/百分比最多两位小数；不改原始数值，不用最终峰值归一化。图例可隐藏线条，拖动底部滑块缩放日期；总览价格图悬停单条线，避免同时弹出几十个合约。

本次真实接口验收：RB五年同月/跨年价差各5条，CU五年同月5条；RB十年持仓占比总览128条、约2.10MB、冷请求约2.18秒。豆粕无10月组合时返回空态，不造数据；同年01—05组合返回5条。浏览器已验证五年对比、跨年价差和68条合约的五年热力图。最终55项测试通过，覆盖同日分母、跨年配对、闰日、缺腿、缺失结算、重复键、截止日隔离、10年读取及不修改源文件。价差横轴限定有有效报价的跨度，内部空值不补齐。
