## 3. 模块补充建议（按交易价值排序）

| 模块 | 最值得补充的信息 | 最小实现与呈现 |
|---|---|---|
| 机会总览 | 同季节偏离、样本年数、信号持续天数、短腿成交/OI、数据日期与可执行阻断原因 | 同时展示存续期与同季节口径；先流动性/完整性过滤再排序，不加一个不透明“AI总分” |
| 跨期分析 | 20/60日价差变动波动率，5/20日最大不利变动，价差与两腿涨跌贡献 | 主图价差、联动子图两腿价格，单位分开；变化用ΔS，不对零/负价差算百分比收益 |
| 期限结构 | 今日、前日、5日前三条曲线；相邻月差与局部凸起；流动性大小 | 同一口径/同一截止日，只显示有观测节点；权威最后交易日未接入前不做伪精确期限年化 |
| 持仓换月 | 全品种总持仓、近/远持仓变动、远月占比及5日变化、成交迁移、可退出天数 | 当前同月季节曲线保留；持仓占比上升是相对变化，不声称同一批投资者移仓；缺挂牌目录要提示总量覆盖边界 |
| 历史合约 | 同月份、同季节的中位数及历史范围；当年高亮；可切换原值/占比 | 默认5年，10年按需；显示有效年度数，不能把相邻窗口数十天当数十个独立年份；春节对齐后置 |
| 基差/基本面 | 地区、等级、税价、交割升贴水、仓储运费资金成本；库存/仓单分列；观测与发布时间分列 | 身份未核验继续禁用；统计现货只能生成“参考/估值基差”，不能称现金可执行套利 |
| 自选/交易计划 | 入场条件、否定条件、最长持有期、退出价差、风险预算、实际双腿、情景净盈亏 | 先小型表单和本地SQLite，复用现有自选；不建订单系统，不把主力自动切换当账户换月 |
| 数据状态 | 源水位、双腿共同日期、真实缺数/休市区别、指标核验状态、异常隔离数 | 异常状态贴近对应图表；技术合格与业务身份合格明确分开；不能用原始采集时间冒充发布时间 |

双腿价格有必要，但不宜把两条高价曲线和小价差挤在同一纵轴。当前折叠两腿方式可保留；进一步增加联动子图比再开新模块更有用。

## 4. 执行与风险统计口径

- 买入价差的可成交估计：ask近−bid远；卖出价差：bid近−ask远。两腿时间戳和盘口量必须有效。日线收盘差不替代它们。
- 等乘数同品种、q手的买价差情景净盈亏：q×乘数×(退出卖价差−入场买价差)−额外往返成本。已经通过bid/ask体现的点差不可再扣一遍。卖价差方向相反。费用/乘数未知时净值为未知，不按0。
- 波动使用价差一阶变动的标准差，单位为报价单位/日；单手金额风险另乘合约乘数。历史最大不利变动按事前选定方向和持有期计算，既要报最差值，也要报样本数；不是未来损失上界。
- 同季节比较固定月份及年份偏移；初版沿用自然月日，只用过去年度同期已观测点。可显示中位数、min/max和年度数，不在5年样本上包装“95%置信区间”。稳健Z/MAD、春节对齐与回归半衰期后置，避免稳定性不足的装饰指标。
- 后续胜率/期望收益必须事前固定选腿、信号和退出规则，t日收盘生成的信号最早按t+1可用价做假设成交；加入成本、漏单/滑点情景、滚动样本外验证。不能用当前存续合约筛选结果反推历史胜率。
- 保证金不能简单把两腿固定比例抵销；规则、账户资格、经纪商口径应分别留证。风险面板还应显示涨跌停导致无法退出的可能性；上期所风险控制办法明确存在受涨跌停等限制而延后完成平仓的情形。[上期所风险控制管理办法，第43、45条](https://www.shfe.cn/regulation/exchangerules/otherrules/202606/t20260622_832192.html)

## 5. 格式样式：保持专业而不继续加重界面

1. 固定上方信息条：品种/两腿/价格口径/共同截止日/日终或实时/异常状态。避免滚动后忘记正在看哪组。
2. 当前年份用醒目粗线，历史用较细线；同一合约在各图保持同色。涨跌色与年份配色分开，异常使用文字+图标，不只靠颜色。
3. 悬停先给日期，再给品种/腿/值/单位；价格按已核验tick精度，未核验时用有限小数显示并保留原始下载；持仓整数、占比两位。不改底层数值来美化。
4. 同季节线只连接无观测的日历空档，不制造周末价格；明确缺失观测继续断线。本轮已完成此修复。
5. 将“机会”分为统计候选、已复核、数据/执行受阻，不用红绿灯直接暗示买卖。复杂口径放折叠区，但关键阻断原因始终显示。
