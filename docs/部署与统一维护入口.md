## 本地构建、发布和回滚

1. 正常停止统一启动器；不要停止原席位或其他会话进程。
2. `./tools/publish_futures.ps1 -CodeOnly` 构建全部前端并冻结期货后端，保留现有数据。命令名兼容旧流程；去掉 `-CodeOnly` 才刷新已保存的期货基本面数据。
3. 前端校验后写入不可变 `runtime/releases/web-<hash>`，原子更新 `runtime/frontend-release.json`。gateway 启动时固定一版；切指针必须受控重启才生效。
4. `./start.ps1 --module seats` 启动，检查三模块，而非只检查变更模块。
5. 回滚前正常停止，执行 `.venv/Scripts/python.exe tools/freeze_backend.py --rollback-frontend` 后重启。前端三模块一起回退，不改 API 和数据。

旧版本资源 URL 在重启后仍可访问，缺失 JS 返回 404 而非 HTML，避免已打开页面懒加载失效。旧完整版本保留；不可在仍有读者时随意清理。前端回滚以兼容现有 v1 API 为前提；破坏性 API 变更须另行安排兼容发布。后端/数据回滚互相独立；本脚本并非三域数据和后端的一体事务发布器。生产发布锁、保留期、读者保护与 GC 由云服务器发布流程管理。

首次克隆、依赖安装见根 README。`OPTIONS_PYTHON`、`FUTURES_PYTHON`、`SEATS_PYTHON` 可指定解释器；`DASHBOARD_RUNTIME_ROOT` 可挂载运行根。发布指针使用相对路径，不向客户端暴露主机路径。数据、发布包、备份、日志均不进 Git。生产已移除测试依赖及 PyArrow，需复验时按锁文件临时安装；回退到旧 `0322814` CLI 前须暂停大阪更新 timer，避免新版消费器向旧 CLI 传入增量参数。

客户端冷启动使用 `no-cache` 验证浏览器私有 HTTP 完整响应，内存差量仍 `no-store`；坏差量/无基线最多无条件重取一次，不新增持久行情仓。当前模块可见时每5分钟或恢复焦点（同一节流）检查小版本端点，隐藏/切换取消；变更提示位于页底，用户点击更新保留 URL 和筛选。失败保留原页面并显示检查失败。版本只比较不透明标识，不假定单调日期；期货/期权版本端点只读取文件元数据，不查历史或解析快照。

## 资源与验收边界

缓存预算沿用期货 96 MiB + 期权 32 MiB + 席位 128 MiB。DuckDB 每连接 256 MB、1 线程；重查询并发 1。它们不是进程 RSS 硬上限。云侧 dashboard.slice 为 MemoryHigh 1792 MiB / Max 2 GiB、CPU 150%；API MemoryLow 384 MiB 保护实际工作集、不预分配，单进程 MemoryMax 512 MiB；后台磁盘读、写各限制为 64,000,000 B/s（64 MB/s，非网络限速）。该现行值依据 2026-10-29 隔离窗口对比选定，实验不代表全量处理性能或长期 SLA；后台 CPU 75%、MemoryMax 1536 MiB 不变。

此前 8 MB/s 限速验收中，衍生构建耗时 3 分 55.57 秒（不含源提取、交付、校验和发布）；主要计算阶段四轮各六个首次查询全部 200，请求前后构建均 active，耗时 0.348–1.950 秒。连续两轮全历史增量的 19 表摘要与全量一致，Linux 63 项测试通过；不是全历史精确集合对照，也不代表长期 SLA。清理后运行依赖约 183 MiB、项目总占用约 904 MiB；重启、342 个输入文件、真实快照、23 项公网请求和 13 步 Chrome 交互复验通过。

本地原始证据位于 `runtime/merge-baseline-20261028`，含迁移前工作区源码包、构建包、逐文件哈希及五个席位真实 API 对照。仅元数据 data_version 因运行路径变化不同；其余业务 JSON 完全相同，条件请求返回 304。共享资源须分别测首访与切换，不能用总 gzip 降幅代表每个模块首屏更快。

上线事实以本文开头的日期记录为准；以下本地与初期云端验收均为历史证据，不代表当前版本或完整生产压测。后续生产变更继续由云服务器会话执行。
