## 日常启动

推荐从统一工程启动：

```powershell
Set-Location 'E:\工作\期权终端'
./start.ps1
```

默认查看 http://127.0.0.1:8790/options/，顶部切换期货研究。也可以使用 `./start.ps1 --module futures`。

从期货目录沿用旧命令也进入同一终端：

```powershell
Set-Location 'E:\工作\期货终端'
./.venv/Scripts/python.exe start.py
```

对应 http://127.0.0.1:8790/futures/。这两个网址只是同一网页应用的两个模块路径，共用同一组后台服务。已有完整健康服务时直接复用，不再重复启动。首次启动器等待两个模块和入口就绪后才提示成功；端口被其他服务占用时退出，不强行关闭已有进程。

开发者明确需要单模块调试时，才运行 `start.py --standalone`，使用8766。该页面不作为统一终端的交付依据。

后续优先级：

1. **公开前的数据边界**：标明数据授权、来源、报价/交易日、延迟和单位。仓单数量不能直接当社会库存；地区、品级、税费、交割折算、注销规则需随指标记录。现货利润必须公开公式及投入品系数，不先补一个无可靠数据的栏目。

3. **可比性与可交易性**：基差保留现货/指数与期货的同日条件、符号及合约标识；负值或近零价差优先看绝对变化，百分比可能失真。季节性保留样本数、缺口和历年真实合约，不能把“同月份合约”“全合约合计”“主连”互换。排行榜分位不等于交易信号，应同时看流动性及历史覆盖。
4. **工作流扩展**：以后可持久化/分享品种、合约、日期和页签，减少反复选择；候选组合当前偏多头，可在口径与数据到位后增加看跌/保护性对冲。优先复用现有图表和计算，不为对齐参考站数量另造页面。
5. **期权解释**：模型估值不等于可成交报价；费用预算、盘口量、乘数、保证金和跨到期处置不能省略。到期估值的标的是结算参考值，不能当盘中指数触达；参见 [中金所股指期权合约交易细则](https://www.cffex.com.cn/u/cms/www/202207/1820311129r5.pdf)。
