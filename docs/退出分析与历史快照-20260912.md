# 退出分析与历史快照

本轮范围：情景损益地图、提前止盈分析、交易成本、手动快照回看入口。沿用现有本地接口与计算函数。

## 使用路径

在“退出分析”选择当前比较篮或已有候选，设置价格范围、持有上限、目标点位、盈利目标及IV变化，更新分析。可切换普通/保守退出热图；下方列出同一目标在各时点到达时的结果，以及价格扫描范围内首个达到盈利目标的点位。

历史选择器读取本机完整保存的Wind原始截面，重新按该截面的日期、期限和报价分析，不修改当前行情指针或全局比较篮。后续手动刷新产生的完整原始截面会自动出现在历史列表；历史保存并不意味着所有字段均有效，缺失报价/IV仍不能用于策略估值。

## 成本口径

页面已按定性观察用途简化：交易成本独立显示、默认折叠，只填每腿每手的往返成本合计估算。结果主卡片保留投入、到期最大亏损和到期最大收益，表格不单列成本损耗。普通/保守损益仍可对照。

页面将合计估算传入全程费用字段，额外点数滑点固定为0，保守退出半价差固定为2倍；旧的滑点与倍数浏览器配置不再应用。以下为计算接口仍保留的完整口径。

- 费用：用户填写的每腿每手全程总费用预算，单位元/手，按手数累计，不能再乘合约乘数。默认0代表尚未设置，不是实际免费。
- 滑点：用户填写的每腿单边期权价格点数。买入入场价格为卖一价加滑点；卖出入场价格为买一价减滑点，最低0。
- 普通提前退出：模型中价减/加当前半价差，再加单边不利滑点。
- 保守提前退出：放大当前半价差，再加同样的不利滑点。它是一项压力假设，不是订单簿冲击预测。
- 到期：直接按目标结算标的计算内在价值，不加退出价差或退出滑点；全程费用仍按用户预算预留。
- 净投入包含入场滑点和预留的全程费用；最大损益为到期口径。跨到期组合的生命周期最大风险仍不输出数值上限。
- `gross_pnl`为沿用原盘口、普通退出价差且未加额外费用/滑点的基准损益；`friction_cost`是相对该基准的额外损耗。原买卖价差已包含在基准内。

## 情景含义

横轴为从所选行情截面起算的日历天数，纵轴为目标指数价格，高价在上；IV按用户输入平移，提前退出保持截面当前基差。结果是条件情景，不是触达概率，也不是实际成交承诺。

盈利目标反查返回价格网格从低到高第一个达标点，不声称是精确根；价差或复杂组合不保证所有更高价格均达标。空值表示扫描范围内未达到或条件不可计算，不用0补值。
