# 审阅优化实施记录

2026-09-12。沿用现有 React/ECharts、期权 API 和隔离期货副本，未改期货源码、采集调度或云部署。

## 本轮实现

1. 到期情景直接按目标结算标的计算内在价值，提前退出保留固定基差与半价差假设。已通过真实接口复现并修正：C7700、目标7800，到期退出价值由82.84点改为100点。
2. 历史行情明确标识；剩余期限和情景均注明截面起算时点。显示预计退出日期，增加“至所选月到期”。目标、天数和IV参数保存本机，新用户目标取截面指数约+1%并按50点向上取整，可自行修改，不再固定7700。
3. 候选筛选采用价差率上限（10%/20%/30%）和双边盘口最小手数（1/5/10）。默认20%、1手；真实盘口量从已保存WSQ字段读取。预算比较采用整数倍组合、最大亏损上限和当前可见盘口量三者约束，展示实际风险占用，不将无法配置的候选显示为零风险。
4. 波动率增加跨月OTM微笑、ATM期限结构、25Delta偏度。微笑坐标K/F；K<F取Put，K>=F取Call；ATM在K/F=1插值，25Delta为贴现远期Delta。偏度=Put25DeltaIV-Call25DeltaIV，单位百分点。报价价差率上限20%，缺口不连线，不外推，不展示缺乏历史样本的IV百分位。
5. 持仓增加增仓、减仓、成交活跃排名；支持昨收OI基准与同日上一截面基准。区间成交由同日累计量相减，负修订显示空。旧截面没有实时量仓时禁用区间比较并说明。
6. 刷新按仍在市月份验收：目录覆盖低于旧值80%、报价覆盖下降超过20个百分点、有IV变成无IV、live量仓覆盖低于80%时拒绝发布，保留旧截面。正常到期和新上市月份区别处理。新指针记录上一截面目录，读取结果按当前截面缓存。
